This repository is a marketing-style Next.js website that documents the open format AGENTS.md. It is implemented as a static-optimized React application with a small amount of client-side interactivity and GitHub API-backed data fetching.

Key Design

The site is a single-page landing page built with Next.js and TypeScript. The root entry is pages/index.tsx, which composes the site from reusable section components.

Core concepts:

  • Static generation with getStaticProps to fetch GitHub contributor metadata at build time.
  • Reusable section components for Hero, compatibility, examples, FAQ, and documentation content.
  • Client-side interactivity in CompatibilitySection.tsx for the agent logo marquee and grid toggle.
  • Tailwind CSS-driven styling using @tailwindcss/postcss plus a single global CSS file.

Component Architecture

The page is composed of the following major components:

  • pages/index.tsx — root page that stitches together sections and fetches contributor metadata.
  • components/Hero.tsx — prominent landing section with CTA buttons and a sample AGENTS.md code snippet.
  • components/CompatibilitySection.tsx — interactive marquee of supported agents with a grid toggle.
  • components/ExamplesSection.tsx — renders an example code block and the repo cards list.
  • components/ExampleListSection.tsx — hard-coded example repos and contributor avatars.
  • components/CodeExample.tsx — Markdown window with copy-to-clipboard support.
  • components/FAQSection.tsx — FAQ content and usage examples for agent configuration.
  • components/HowToUseSection.tsx — usage guidance for adding AGENTS.md files.
  • components/AboutSection.tsx — project background and stewarding organizations.
  • components/Section.tsx — wrapper component for section layout and headings.

The reusable Section component standardizes section spacing, maximum width, headings, and prose styling.

Build / Runtime Flow

This project uses:

  • Next.js 16 for React server-side rendering and static generation.
  • pnpm as the package manager.
  • Tailwind CSS v4 via @tailwindcss/postcss.
  • TypeScript with strict settings and path alias @/*.

Page data generation is handled by getStaticProps in pages/index.tsx. It fetches contributor avatars from GitHub for the example repo cards, caches the results in-memory during the Node process lifetime, and revalidates on a schedule.

The interactive compatibility section runs on the client and uses IntersectionObserver to pause or play marquee animation depending on viewport visibility.
